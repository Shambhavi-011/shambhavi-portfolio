# ✨ Shambhavi's Developer Portfolio

A personal portfolio website built to showcase my projects, skills, certifications, education, and development journey.

This portfolio is not just a template — I built it using the technologies I have learned and worked with, and tried to keep the design clean, modern, simple, and true to my style.

---

## 🌸 About This Portfolio

I wanted my portfolio to feel more personal than a normal resume website.

So instead of adding unnecessary sections or flashy elements, I focused on:

- Clean and minimal UI
- Responsive design
- My actual projects and skills
- Smooth project filtering
- Backend-powered project data
- Simple navigation
- A professional but friendly look

This project represents what I currently know and the kind of developer I am becoming.
